# TinyIMX main 发布与入口整理

## 发布目标

默认分支提供完整后端、Qt6 客户端、协议、数据库结构、部署、测试与性能文档，同时将根 README 整理为可浏览的产品介绍。

## 源码与历史

- 原 GitHub main 为独立初始化提交 `545b9e6a0476ab6a5b65e0cbc5a63ade6d81c23a`，仅含简短 README。
- 完整开发分支为 `work/local-capacity-10k-50k-20261004`，已发布头为 `73543d7730b723c56dd9739114e4674fa472b8f7`。
- Ubuntu 最新已提交版本 `f2e4320dd1fa2f2e298ed841675e1a8accbb185c` 仅增加复盘文档与 README 入口。原始内部复盘在本地保留，公开树采用不含私有环境元数据的产品与技术复盘。
- main 使用正常合并提交，保留初始化与完整开发分支两条祖先历史。原分支不删除，不强推，不重写已有提交。

## 整理与修正

| 发现的问题 | 处理 |
| --- | --- |
| 默认 main 看不到完整项目 | 以完整开发树为基础准备发布，保留双方历史 |
| README 偏向本机交接 | 新增产品介绍、真实截图、功能全景、架构 / 消息图、技术栈、性能证据与导航 |
| 生产脚本固定旧分支名 | 改为验证当前 Git 源码工作区，允许 main 与开发分支 |
| 空间助手会删除编辑器缓存 | 改为只读审计，保留缓存与构建目录 |
| 运行镜像未包含桌面文件入口 | 将现有 `desktop_file_server` 纳入运行包，并增加可选 Compose overlay |
| 新用户缺少自己的账号 | 新增先预检、显式应用、仅插入新用户的便携演示账号助手 |
| 客户端构建文档依赖本机助手 | 提供 Qt Creator、标准 CMake 与 windeployqt 路径 |
| 简历与构建标准易混淆 | 按实际 CMake 明确后端 C++20、Qt 客户端 C++17 |

## 指标与范围

保留万人指定负载与 ABBA 优化证据，也保留两万人失败及五万未验收结论。未把普通功能联调、UI 预览或模型演示写成全功能容量通过。桌面 Ollama 与后端 MCP 分别说明。

## 公开材料处理

上传审查发现原始复盘包含私有环境和内部证据元数据。本次公开版本重新整理为产品功能、工程设计、边界与公开文档索引，不公开原始内部审计材料；源代码和已有公开开发历史完整保留。

## 操作边界

发布在独立源码副本中准备；Ubuntu 原工作区三处未提交诊断脚本保留。此次不恢复压测、不重建现有容器、不改账号或数据、不调整本机应用，不处理已暂停的 GitLab。

新增部署入口以静态配置、shell 语法和隔离验证进行检查；本次发布未在空白机器完成全套依赖编译和真实冷部署，相关步骤以快速开始和模块门槛输出逐项核对。
