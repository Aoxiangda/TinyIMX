14. 如何自己查看账号、群组与文件
========================================================================
优先用三个UTF-8索引搜索用户名、群ID、文件ID。账户索引包含ID/用户名/昵称/状态/创建与最后登录；群索引含群主/策略/有效成员数；文件索引含所有者/大小/状态/存储相对键。
群状态1有效、2解散；文件状态1上传、2校验、3可用、4失败、5取消、6过期、7删除。记录存在不代表可下载，应用仍需检查权限/状态。
Ubuntu终端可以从容器环境传入已有管理密码，不将值写在命令中。中文必须指定utf8mb4。以下进入只读事务，仅查询指定数据，不执行UPDATE/DELETE。


docker exec -it tinyimx-m21-mysql-1 sh -c 'MYSQL_PWD="$MYSQL_ROOT_PASSWORD" exec mysql -uroot --default-character-set=utf8mb4 "$MYSQL_DATABASE"'

-- mysql控制台内：
SET SESSION TRANSACTION READ ONLY;
START TRANSACTION;
SELECT user_id,username,nickname,status FROM im_users WHERE user_id BETWEEN 750001 AND 750006 ORDER BY user_id;
SELECT group_id,name,owner_user_id,status FROM im_groups ORDER BY group_id DESC LIMIT 20;
SELECT file_id,owner_user_id,file_name,total_size,status,storage_key FROM im_files ORDER BY file_id DESC LIMIT 20;
ROLLBACK;
