# Windows 原生50K负载端与独立状态核验

本目录保存两档正式50K工作点实际使用的Go源码。`r1788`用于1000条/秒工作点；`r1795`用于1250条/秒工作点，其共享心跳到期调度与64个有界回复线程减少逐账号任务占用。二者消息发送、ACK、投递与计时循环保持一致。

源码只依赖Go标准库，使用Windows专用单调时钟、端口独占预约与TCP设置。在对应子目录执行 `go build -o tinyimx_load.exe .` 可构建工具；`go test ./...` 检查计时、帧拆分、端口与心跳等本地契约。运行参数以工具 `--help` 为准。实际正式实验使用的服务器配置、已创建的独立账号及授权好友关系须另行准备。

`closed_capacity_pattern_audit.cpp` 是实际使用的独立只读存储核验器源码；它依赖TinyIMX Native存储引擎及对应构建依赖。报告结果由全部正文、CID、历史、未读、接收确认和待处理索引核对产生。

公开结果与程序哈希见 [50K报告](../../docs/performance/FINAL_CAPACITY_20261027.md)和[结构化结果](../../docs/performance/results/fixed50k-20261027.json)。本目录不包含业务账号密码、私有配置、客户端逐条私有会话记录或编译二进制。
